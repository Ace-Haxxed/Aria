Installing

    What it can do

    • See and describe your screen
    • Click, type and drive any application
    • Find, organise and edit files
    • Search the web and read pages
    • Fill in forms and download files
    • Run scripts and shell commands
    • Manage windows and applications
    • Control volume, brightness and power
    • Install and update system packages
    • Answer by voice, fully offline
    • Analyse photos from your camera
    • Set timers and reminders

    Runs entirely on your machine

    Pair Jarvis with Ollama and nothing leaves your device — no API key, no account, no network. Cloud backends (Groq, OpenAI, Anthropic, Gemini) are there if you want the extra capability. There is no telemetry either way.
